# GesForma — protótipo ENA

Backoffice de gestão de formação (Gold / autofinanciada e Financiada), a partir do protótipo de alta fidelidade.

Inclui o **dossiê técnico-pedagógico (DTP) por ação**, com checklists diferentes:

- **Gold / CCP** — núcleo DGERT + PIP, simulações, 5 anos de experiência, recibos
- **Financiada / UFCD** — núcleo DGERT + elegibilidade, IBAN, horas, relatório de execução

## Correr localmente

```bash
npm install
npm run dev
```

Abre [http://127.0.0.1:43147](http://127.0.0.1:43147).

Atalhos na demo: **Dossiê TP** no menu Gold e Financiada, **Abrir DTP** no cockpit da turma, botão de documentos nas turmas financiadas.
