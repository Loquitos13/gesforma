# Disponibilidade do formador

A ficha do formador mostra um calendário, mês a mês. Cada dia pode ficar disponível (com um ou mais horários) ou indisponível.

Ainda não está decidido quem preenche esse calendário:

- a secretaria, na ficha
- o próprio formador, com acesso à Gesforma
- uma API de calendário partilhado, como o Google Calendar

Até essa decisão, a marcação faz-se na ficha. O cronograma só avisa quando o dia da sessão já está marcado e não cobre o horário.
